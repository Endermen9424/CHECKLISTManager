# CHECKLIST Manager v1.0
Manage your aircraft checklists easily:
>You can view, add, and delete your checklists and aircraft brands.
>When you are adding new checklist, if the brand does not exist, it will be created automatically.
>You should add a link or file path in to the checklist field when you are creating a new checklist.
>All checklist of that brand will be delete, when you are delete a brand.
